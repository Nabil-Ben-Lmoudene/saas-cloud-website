# About This Project

**SaaS Cloud** is a fictional SaaS website that I designed and developed as a portfolio project.

The project was created to demonstrate my ability to take a website from the **initial UI/UX design stage to a complete responsive front-end implementation**, while also considering SEO and accessibility.

I first designed the website pages and user interface in **Figma**, then translated the designs into a functional website using **HTML, CSS, Tailwind CSS, and JavaScript**.

The project includes both the original Figma designs and the developed website.
